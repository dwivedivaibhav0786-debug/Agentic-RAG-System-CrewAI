# Agentic RAG using CrewAI

## Features

- Multi Agent Architecture
- CrewAI
- PDF RAG
- Web Search
- Weather API
- Streamlit UI
- FAISS Vector Database

## Installation

```bash
pip install -r requirements.txt
```

Run

```bash
streamlit run app.py
```

- OpenAI
- Serper
- OpenWeather
